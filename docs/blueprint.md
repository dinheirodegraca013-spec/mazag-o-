# **App Name**: Mazagão Flow

## Core Features:

- Conversion Redirection Tool: A lead-routing tool that uses reasoning to incorporate user location and profile data into personalized WhatsApp order messages.
- AI Marketing Insights Tool: An analytical tool that uses reasoning to evaluate user behavior and campaign performance to suggest winning headlines, optimal posting times, and high-conversion CTAs.
- Predictive Reorder Tool: An AI tool that uses reasoning to analyze consumer purchase history and consumption frequency to decide when to trigger automated repurchase reminders via WhatsApp.
- Operational CRM Pipeline: A visual drag-and-drop lead management system for tracking orders from the 'New Lead' phase through 'Out for Delivery' to 'Completed Order'.
- Integrated Ads Dashboard: Real-time monitoring hub for Google, Meta, and TikTok ads tracking ROI, ROAS, and CAC across specific regional campaigns.
- Behavioral Heatmaps & Replays: Visual tracking of user scroll depth, click points, and session recordings to optimize the mobile conversion experience.
- Automated Workflow Builder: A logic-based system to create custom automation sequences, such as triggering follow-up messages if a user abandons a lead form.
- Neon Interactive Gallery: Glass-morphism style product cards showcasing P5 to P45 cylinders with interactive glow effects and hover-activated buy triggers.
- Operational Heatmap: Interactive regional map showing high-demand areas, active delivery routes, and coverage zones in Guarujá.
- Cinematic Motion Intro: A 3-5 second high-impact entry sequence featuring urban neon visuals and logistics-themed transitions.
- Cyber-Ops Master CMS: A high-performance administrative panel with a dark-mode 'Cyber Operational' aesthetic for managing banners, prices, and user permissions.

## Style Guidelines:

- Primary background: Deep Midnight Blue (#0A0D2B) for a premium cinematic night-mode aesthetic.
- Primary accent: Neon Green (#B8FF00) for action buttons and high-priority conversion elements.
- Secondary brand color: Electric Blue (#1D22D8) for secondary CTAs, glow effects, and branding.
- Headlines use 'Anton', 'Bebas Neue', or 'Oswald' for a bold, industrial, and condensed high-impact feel.
- Body text uses 'Montserrat' for clean readability across all mobile devices.
- Lean, technical icons with neon stroke glows and subtle pulse animations to signify active operations.
- Mobile-first 'Thumb-Zone' architecture with persistent floating WhatsApp triggers and glass-morphism overlays.
- High-velocity motion blur transitions and cinematographic fades to communicate speed and reliability.
