# Pasta de Imagens Mazagão Gás

Coloque aqui as imagens que você deseja exibir no site.
Os nomes de arquivos esperados pelo sistema são:

- `hero.jpg` (Imagem de fundo principal)
- `intro.jpg` (Imagem da intro cinematográfica)
- `p5.png` (Botijão P5)
- `p13.png` (Botijão P13)
- `p20.png` (Botijão P20)
- `p45.png` (Botijão P45)
- `mapa.png` (Mapa de cobertura)

Certifique-se de manter a extensão correta (.png ou .jpg) ou ajuste o arquivo `src/app/lib/placeholder-images.json` se mudar os nomes.
